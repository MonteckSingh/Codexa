# CODEXA UI/UX Landing Page

Files:
- index.html — semantic page structure
- style.css — responsive CSS3 design
- script.js — mobile navigation, modal enquiry form, service preselection, interactions

Open `index.html` directly in a browser.

The form is intentionally frontend-only. Connect the submit handler to your backend, CRM, Formspree, Google Apps Script, or API endpoint for production lead capture.
